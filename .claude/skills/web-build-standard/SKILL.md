# תקן בנייה — אתרי נחיתה בעברית

הרף המקצועי לכל עבודה על ה-repo הזה. **הפלטה והגופנים מגיעים מהמיתוג של הלקוח**
— המסמך הזה מגדיר איך בונים, לא באיזה צבע.

---

## 1. טיפוגרפיה עברית — הכללים שנשברים הכי הרבה

- **בלי `letter-spacing` חיובי על עברית.** זה נראה שבור. tracking שמור לטקסט לטיני ולמספרים בלבד.
- **כותרות עבריות צריכות משקל כבד ו-tracking שלילי** (`-0.03em` עד `-0.055em`) ו-`line-height` קרוב ל-1. בלי זה שורה עברית מתפרקת לאותיות בודדות.
- `overflow-wrap: break-word` על כותרות — בזום 200% במסך צר מילה עברית ארוכה גולשת מהעמודה.
- מספרי טלפון ותאריכים בתוך טקסט עברי — לעטוף ב-`<bdi>` או `dir="ltr"` כדי שה-bidi לא יהפוך אותם.
- להשתמש ב-`inset-inline-start/end`, `margin-inline`, `padding-block` — לא ב-`left/right`.

## 2. נגישות — חובה חוקית בישראל, לא נחמד שיהיה

- **0 כשלי WCAG AA.** 4.5:1 לטקסט רגיל, 3:1 לטקסט גדול. **למדוד, לא להעריך.**
- אזורי לחיצה 24px לפחות.
- ניווט מקלדת מלא + `:focus-visible` גלוי + קישור דילוג לתוכן.
- `prefers-reduced-motion` מכובד — כל האנימציות נעצרות.
- **הדף חייב לעבוד בלי JavaScript.** אם משתמשים ב-scroll-reveal, להסתיר רק תחת מחלקה שה-JS מוסיף (`.js`), אחרת הדף ריק כשהסקריפט נכשל.
- **הצהרת נגישות + כפתור נגישות בכל דף** — כולל בדף ההצהרה עצמו. ת"י 5568.

## 3. מבנה הדף — שני חוקים

**הוכחה לפני בקשה.** עבודות, עדויות ותוצאות באות **לפני** הסקשן שמבקש להשאיר פרטים.
לבדוק: באיזה אחוז מהדף מופיעה הבקשה הראשונה, ובאיזה ההוכחה הראשונה. אם הבקשה מוקדמת
יותר — המבקר מתבקש להתחייב לפני שהוכחת שאתה יודע לעבוד.

**משטחים.** תוכן (טקסט, רשימות, טפסים) יושב בכרטיסים עם רקע. אובייקטים (תמונות חיתוך,
איורים, דיוקנאות) צפים חופשי על הרקע. לערבב = הדף נראה מבולגן בלי שאפשר להצביע למה.

## 4. תשע מלכודות — כל אחת עלתה בבאג אמיתי

| מה | מה קורה |
|---|---|
| `background:` shorthand על טקסט עם `background-clip:text` | מאפס את ה-clip ל-`border-box` → **הכותרת נעלמת**. תמיד `background-image:` |
| `inline-block` בתוך אלמנט עם `background-clip:text` | ההורה מצייר את הטקסט **פעם שנייה** במיקום אחר. לוותר על ה-clip באותה שורה |
| `overflow:hidden` על סקשן שמכיל `position:sticky` | הורג את ה-sticky לגמרי. להשתמש ב-`overflow:clip` |
| `img` בלי `height:auto` | מאפייני `width`/`height` של ה-HTML **מועכים את יחס התמונה** |
| `mask-image` בלי `-webkit-mask-image` | לא עובד בספארי לפני 15.4 — מסכות והיעלמויות נשברות באייפונים ישנים |
| `IntersectionObserver` ל-scroll reveal | מפספס אלמנטים בקפיצת עוגן → סקשנים שלמים נשארים בלתי נראים. עדיף בדיקת מיקום ב-scroll handler |
| מרקיזה ב-RTL | התזוזה חייבת להיות **חיובית**. שלילית מרוקנת את המסך במקום למלא אותו |
| `backdrop-filter` על אלמנטים בתנועה מתמדת | יקר מאוד ב-GPU בטלפונים. ברקע נע — רקע חצי-אטום במקום |
| מחלקה חדשה עם גרדיאנט על טקסט | חייבת להתווסף לכלל של מצב ניגודיות גבוהה, אחרת היא **נעלמת** בדיוק אצל מי שהכי צריך לקרוא |

## 5. ריווח שנגזר מתוכן, לא ממספר קבוע

כשכותרת ענקית יושבת ברקע והתוכן צריך לרדת מתחתיה — **`line-height` לא מספיק**.
בגופנים כבדים תיבת השורה **קטנה מהגליפים**, והאותיות גולשות ממנה. למדוד את גובה הדיו
האמיתי (Canvas `measureText`) ולגזור את הריווח ממנו.

## 6. לפני שמדווחים "סיימתי"

```
□ ניגודיות: 0 כשלים — נמדד בדפדפן, לא הוערך
□ צילום מסך דסקטופ + מובייל 390px, ונבדק בעיניים
□ 320px: אין גלילה אופקית, אין טקסט נחתך
□ עובד עם JavaScript מושבת
□ מצב ניגודיות גבוהה: שום דבר לא נעלם
□ כל התמונות נטענות
□ המלכודות שנגעתי בהן מתועדות
```

**שינוי שלא ראית בעיניים הוא שינוי שלא קרה.** הדפדפן שומר CSS ו-JS ב-cache —
לרענן עם `Ctrl+Shift+R` או להוסיף query לקובץ, אחרת בודקים את הגרסה הישנה.

**כשמדידה יוצאת רועשת — לומר שהיא חסרת ערך, לא להישען עליה.**
