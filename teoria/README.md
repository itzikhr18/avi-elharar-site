# סקשן תיאוריה — עבודה בתהליך

**הדפים כאן מסומנים `noindex` ואינם ב-sitemap.** `scripts/validate_site.py`
אוכף את שני התנאים: דף טיוטה שייכנס ל-sitemap ייכשל ב-CI.

## ⛔ שער פתוח: רישיון מאגר השאלות

`data/questions.sample.json` מכיל **שאלות דמה שנכתבו לצורך פיתוח בלבד**.
הן אינן מהמאגר הרשמי.

לפני שמכניסים ולו שאלה אחת מהמאגר של משרד התחבורה, חובה:

1. לפתוח בדפדפן את <https://www.gov.il/he/pages/theoryexamhe_data_info>
   ואת <https://data.gov.il/he/datasets/ministry_of_transport/tqhe>
   ולקרוא את תנאי השימוש. **שני העמודים חוסמים קריאה אוטומטית (403), ולכן
   התנאים לא אומתו מתוך הסביבה הזו — רק מסיכומי חיפוש.**
2. לוודא מה בדיוק נדרש בייחוס. לפי הסיכום: שם האתר, שם מאגר הנתונים,
   ותאריך העדכון — שלושתם חייבים להופיע בדף.
3. לברר בנפרד את מעמד **קובצי התמונות** של התמרורים. הכוונה כרגע לצייר
   ספרייט SVG עצמאי במקום להסתמך עליהם.

עד שזה נסגר — לא מכניסים תוכן אמיתי.

## מבנה

```
teoria/
  index.html            hub
  simulator/index.html  סימולציית מבחן
  teoria.css            סגנונות של הסקשן בלבד
  teoria.js             מנוע השאלון
  data/*.json           מאגר, מפוצל לפי נושא
```

## כללי בידוד (לא לשבור)

- אין לגעת ב-`style.css`, `main.js`, `index.html` (שורש), `sitemap.xml`,
  `robots.txt`. הדפים כאן **טוענים** את `style.min.css` המשותף אבל לא
  משנים אותו — כך שהאתר החי מגיש בדיוק את אותם בתים.
- כל CSS/JS חדש נכנס ל-`teoria.css` / `teoria.js` בלבד.
- החיבור לאתר (קישור בתפריט, sitemap, הסרת `noindex`) הוא **קומיט אחרון
  ונפרד**, שאפשר לקרוא ולבטל בשלמותו.

## מה שעדיין חסר כדי שזה יהיה שווה משהו

הערות הבוחן. בלי `examinerNote` אמיתי על השאלות, זה שכפול של שבעה אתרים
קיימים ואין סיבה שמישהו יגיע לכאן. זה החסם, לא הקוד.
