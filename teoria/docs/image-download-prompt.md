# פרומט לכלי החילוץ — הורדת 439 תמונות המאגר הרשמי

העתק את כל מה שמתחת לקו לכלי שהריץ את החילוץ הקודם.

---

## הרקע

בהרצה הקודמת חילצת את `images-index.json` — מיפוי של **439 שמות קבצים לכתובות URL**
בשרת של משרד התחבורה, בצורה:

```json
{ "TQ_PIC_3190.jpg": "https://www.gov.il/BlobFolder/generalpage/tq_pic_01/he/TQ_PIC_3190.jpg" }
```

חילצת את הכתובות אבל **לא את הקבצים עצמם**. בלעדיהם **553 מתוך 1,273 שאלות דרגה B
(43.4% מהמאגר) לא ניתנות להצגה** — השאלה מפנה לתמונה שאיננה. זו המשימה.

הסביבה שבה אני עובדת חוסמת את `gov.il` ברמת הרשת (403 ל-CONNECT). אין לי דרך להוריד
בעצמי. המחשב שלך כן מגיע לשם — הוכחת את זה בהרצה הקודמת.

## יעד 1 — הורדת 439 התמונות (חובה)

קלט: `out/images-index.json` (הקובץ שכבר יצרת).

הורד כל אחת מ-439 הכתובות אל `out/images/<שם הקובץ>`.

**דרישות:**

1. **קצב מנומס** — לא יותר מ-2 בקשות לשנייה, עם `User-Agent` אמיתי. אל תפיל להם את השרת.
2. **retry** — עד 3 ניסיונות עם השהיה עולה. אם נכשל אחרי 3 — רשום ככישלון, אל תשתיק.
3. **⚠️ ודא שקיבלת תמונה ולא דף שגיאה.** שרתי ממשלה מחזירים לעיתים `200 OK` עם HTML
   של "הדף לא נמצא". בדוק **את שני אלה**:
   - `Content-Type` מתחיל ב-`image/`
   - הבתים הראשונים הם חתימת JPEG (`FF D8 FF`) או PNG (`89 50 4E 47`)

   קובץ שנכשל באחד מהם — **לא נחשב הצלחה.** רשום אותו ככישלון עם הסיבה.
4. **מדוד כל קובץ בפועל** — רוחב, גובה, גודל בבתים, `sha256`. אל תניח שהם זהים.

**פלט:** `out/images/` + `out/images-manifest.json`:

```json
{
  "downloadedAt": "2026-08-02T00:00:00Z",
  "requested": 439,
  "succeeded": 0,
  "failed": 0,
  "files": {
    "TQ_PIC_3190.jpg": {
      "url": "...", "bytes": 0, "width": 0, "height": 0,
      "sha256": "...", "contentType": "image/jpeg"
    }
  },
  "failures": [ { "file": "...", "url": "...", "reason": "..." } ]
}
```

**אם קובץ כלשהו נכשל — כתוב את זה במפורש בראש הדוח.** אל תדווח על 439 הצלחות אם היו 431.

## יעד 2 — טבלת התמרורים הרשמית עם תמונות (חשוב מאוד)

זה עשוי לפתור בעצמו את הבעיה הקשה ביותר שנותרה.

בהרצה הקודמת הבאת את `signs.json` — 438 תמרורים עם **קוד ושם מילולי בלבד**
(`shape` ו-`colors` היו `null` בכולם). מה שחסר הוא **תמונה לכל קוד תמרור**.

חפש באתר משרד התחבורה / הרשות הלאומית לבטיחות בדרכים את טבלת התמרורים הרשמית
שבה מוצגת **תמונה לצד כל קוד**. אם קיימת:

- הורד תמונה לכל קוד תמרור → `out/signs/<קוד>.<סיומת>` (למשל `out/signs/301.png`)
- כתוב `out/signs-manifest.json` באותו מבנה כמו למעלה, עם שדה `signCode` לכל רשומה
- אותן בדיקות תקינות מיעד 1

**אם לא מצאת טבלה כזו — אמור זאת במפורש. אל תרכיב מיפוי מניחוש שמות.**
בדקתי את זה כאן: התאמת שם מדויקת בין התמונות לתמרורים נתנה 5.8% בלבד, מקורבת 9.2%.
ניחוש שמות ייצור מיפוי שגוי שנראה נכון — וזה גרוע יותר מכלום.

## יעד 3 — תנאי השימוש, כלשונם (חובה)

אני צריכה להכריע בשאלת הרישוי ואיני יכולה להגיע לאתר.

שלוף את **הטקסט המלא, מילה במילה** של:

1. תנאי השימוש של `gov.il` (בדרך כלל `https://www.gov.il/he/pages/terms_of_use`)
2. דף המידע על המאגר — `https://www.gov.il/he/pages/theoryexamhe_data_info`
3. עמוד המאגר ב-`data.gov.il`, כולל שדה הרישיון אם קיים

→ `out/terms.md`, עם כתובת ותאריך שליפה לכל אחד.

**אל תסכם ואל תפרש. הבא ציטוט מלא.** אני צריכה לקרוא את הנוסח עצמו, ולא תיאור שלו.
בפרט — האם יש הגבלה על **התמונות** להבדיל מהטקסט, והאם נדרש נוסח ייחוס מסוים.

## מה לא לעשות

- **אל תוריד תמונות מגוגל תמונות, מאתרי תרגול מסחריים או מכל מקור שאינו רשמי.**
  עיצוב התמרור חופשי (סעיף 6 לחוק זכות יוצרים — אין זכות יוצרים בתקנות), אבל
  קובץ שמצאת אצל אתר אחר הוא היצירה שלו, לא התקנה. רק מקורות רשמיים.
- **אל תשנה, תחתוך, תדחס או תמזער את התמונות.** הבא אותן כפי שהן. העיבוד נעשה אצלי.
- **אל תמציא מיפויים.** אם משהו לא ודאי — רשום אותו כלא ודאי.
